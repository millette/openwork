---
title: "Work in Mac apps"
description: "Let the agent use one Mac app window while you watch, take over or stop"
---

Computer use lets the agent work in a Mac app for a task you ask for in a chat.
It needs macOS 14 or later and the OpenWork desktop app. Use the built-in
browser for websites, and a connected app when one exists: both are faster and
more precise.

## Turn it on

Ask for a task in a Mac app, for example: "In TextEdit, tidy up the open
document's headings." The first time, a card above the message box asks you to
set up computer use. The agent waits and carries on by itself once you're done,
so you never have to ask again.

1. Choose **Set up**. A checklist opens with both macOS permissions.
2. Choose **Open Accessibility**, then **Open Screen Recording**. In System
   Settings, turn on the app the checklist names. That's **OpenWork** in an
   installed app. A small guide next to System Settings shows which step is
   left, and the checklist updates on its own. If macOS offers **Quit &
   Reopen**, choose **Later**.
3. Choose **Allow for this chat**, or **Always allow** so every chat can use this
   Mac without asking.

You can also do this anytime from the **Computer** button at the top right of
the chat. A green dot means this chat is allowed. Allowing is saved, including
after a restart, and a window you approve once in a chat opens again without
asking.

If a switch is already on but the checklist still waits, macOS may be holding
an old entry after an update. Choose **Already on? Reset and ask again**, and
macOS asks once more.

## Watch and take over

When the agent opens an app, a floating **Computer** view appears over the
chat with a live picture of the approved window. Drag it anywhere, minimize it,
or expand it to full screen (press Escape to return). If the app has several
windows, choose one in the view.

On your screen, the agent's cursor shows where it clicks and types, with a short
note about what it is doing. A pill sits over the app window's buttons; click it
to **Take over**, **Continue** or **Stop**. Using the app yourself also pauses
the agent. Only you can hand control back with **Continue**.

## Stop

**Stop** in the Computer view or on the pill ends the current task; the chat
stays allowed for your next message. **Stop & revoke** from the Computer button
turns computer use off for that chat until you allow it again. When a chat
finishes its turn, the agent hands the Mac back on its own.

## Privacy and limits

Only the approved window is captured, not your whole desktop, and its content
goes to your selected AI model provider. Standard password fields are omitted.
Enter passwords and answer security prompts yourself.

The agent cannot use OpenWork itself, quit or hide apps, or switch apps with
keyboard shortcuts. Allowing computer use does not approve purchases, sending
messages or deleting files: ask for those clearly and stay present for
sensitive work. Only one chat can use the Mac at a time. Windows and Linux are
not supported.
