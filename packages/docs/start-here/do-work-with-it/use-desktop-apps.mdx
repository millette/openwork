---
title: "Work in Mac apps"
description: "Let the agent use one Mac app window while you watch, take over or stop"
---

Computer use lets the agent work in a Mac app for a task you ask for in a chat.
It needs macOS 14 or later and the OpenWork desktop app. Use the built-in
browser for websites, and a connected app when one exists: both are faster and
more precise.

## Turn it on

1. In a chat, click the **Computer** button at the top right of the chat.
2. Choose **Set up permissions** the first time. Grant **Accessibility** and
   **Screen Recording** to **OpenWork Computer Use** in System Settings. A small
   guide opens next to System Settings and shows which step is left. OpenWork
   never changes these switches for you.
3. Choose **Allow for this chat**, or turn on **Always allow** so every chat can
   use this Mac without asking again.
4. Ask for the task, for example: "In TextEdit, tidy up the open document's
   headings."

A green dot on the Computer button means this chat is allowed. Allowing alone
does not start work.

## Watch and take over

When the agent opens an app, a floating **Computer** view appears over the
chat with a live picture of the approved window. Drag it anywhere, minimize it,
or expand it to full screen (press Escape to return). If the app has several
windows, choose one in the view.

On your screen, the agent's cursor shows where it clicks and types, with a short
note about what it is doing. A pill sits over the app window's buttons; click it
to **Take over**, **Continue** or **Stop**. Using the app yourself also pauses
the agent. Only you can hand control back with **Continue**.

## Stop

Use **Stop** in the Computer view or on the pill, or **Stop & revoke** from the
Computer button. Stopping ends the session and turns computer use off for that
chat until you allow it again. When a chat finishes its turn, the agent hands
the Mac back on its own; your permission for that chat stays.

## Privacy and limits

Only the approved window is captured, not your whole desktop, and its content
goes to your selected AI model provider. Standard password fields are omitted.
Enter passwords and answer security prompts yourself.

The agent cannot use OpenWork itself, quit or hide apps, or switch apps with
keyboard shortcuts. Allowing computer use does not approve purchases, sending
messages or deleting files: ask for those clearly and stay present for
sensitive work. Only one chat can use the Mac at a time. Windows and Linux are
not supported.
